# Proyecto Física

Aplicación de escritorio en **JavaFX** con ejercicios de física, inicio de sesión y una tabla de posiciones (*leaderboard*). Guarda el progreso de cada usuario en una base de datos.

## Funcionalidades
- Login y sesión de usuario
- Lista de ejercicios y vista para resolverlos
- Estado de cada ejercicio por usuario
- Leaderboard

## Tecnologías
Java, JavaFX (FXML), JPA/Hibernate, MySQL, Maven.

## Cómo ejecutar
1. Crea una base de datos MySQL (la URL de ejemplo es `proyecto_fisica_demo`).
2. Revisa `src/main/resources/META-INF/persistence.xml` con tus credenciales.
3. Ejecuta `HelloApplication` desde el IDE.

## Proyecto de aprendizaje
Práctica de JavaFX con JPA y separación de controladores, modelos y servicios.
